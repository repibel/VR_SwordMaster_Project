# ⚔️ VR Sword Fighting Multiplayer Game Project

유니티(Unity) 엔진과 스팀(Steam) 플랫폼을 기반으로 하는 **1대1 대전 중심의 현실적인 물리 기반 VR 검술 게임** 개발 프로젝트입니다.

---

## 📌 핵심 개발 철칙 (Core Principles)

### 1. 무기 베이스 제한 (Weapon Base)
* 초기 개발 및 런칭 버전은 **장검(Longsword)** 단일 무기군으로 한정합니다.
* 완성 이후 대검, 단검 등 다른 무기들을 원활하게 추가할 수 있도록 **컴포넌트 및 스크립터블 오브젝트(Scriptable Object) 기반의 확장성 있는 구조**로 설계합니다.

### 2. 하이브리드 이동 및 모드 전환 (Movement & Combat Mode)
* **기본 상태 (Normal Mode)**: 조이스틱을 이용한 자유로운 이동이 가능합니다. 이 상태에서는 검에 전달되는 물리적 힘이 $0$으로 적용되어, 검을 휘두르더라도 상대방에게 밀리거나 최소한의 데미지만 입힙니다.
* **전투 상태 (Combat Mode)**: 컨트롤러의 **트리거(Trigger)를 누르고 있는 동안** 전환됩니다.
  * 전환 시 **조이스틱 이동이 전면 차단**되며, 플레이어는 실제 현실 몸짓으로만 움직여야 합니다.
  * 이 상태에서만 공격(Attack)과 가드(Guard)가 확실하게 판정되며 물리 공식에 따른 힘이 온전히 전달됩니다.

### 3. 물리 기반 가속도 및 파지법 공식 (Physics Formula)
* 검을 휘두를 때 컨트롤러의 실시간 **속도(Velocity)** 및 **가속도(Acceleration)**를 연산합니다.
* 무기를 **한손**으로 쥐었는지, **양손**으로 쥐었는지에 따라 물리 공식의 가중치(Modifier)가 동적으로 변경됩니다.
* 상대방의 공격을 막아낼 때(Guard) 적용되는 충격량 상쇄 및 튕겨나가는 힘 역시 이 기본 공식을 바탕으로 계산됩니다.

### 4. 무기 중량 및 추적 딜레이 시스템 (Weight & Lag Simulation)
* 무기별로 중량(Weight) 개념을 도입하여 실제 컨트롤러의 움직임과 인게임 무기의 움직임 사이에 **시각적·물리적 딜레이(Lag)**를 부여합니다.
* **대검(Greatsword) 등의 중량 무기 예시**:
  * 한손 파지 시 조작 불가(들지 못함) 처리.
  * 양손으로 들더라도 위로 올릴 때는 컨트롤러 속도보다 느리게 추적(중량감 표현).
  * 아래로 내려찍을 때는 중력 가속도를 추가 반영하여 컨트롤러보다 빠르게 하강.
* 무기의 공격력은 무기의 중량에 비례하여 산정됩니다.

### 5. 1대1 스팀 멀티플레이어 환경 (Network)
* **스팀(Steam) P2P 환경** 기반의 네트워크 아키텍처를 구축합니다.
* 오직 **1대1 매치메이킹 및 대전**만 가능하도록 방 구성과 동기화 로직을 최적화합니다.

---

## 🛠 기술 스택 (Tech Stack)

* **Engine**: Unity 2022.3 LTS 이상
* **VR SDK**: Unity Input System + OpenXR / XR Interaction Toolkit (XRI)
* **Physics**: Rigidbody + Configurable Joint (물리 기반 검 인터랙션 구현)
* **Network**: Photon Fusion (네트워크 물리 동기화 최적화) + Steamworks.NET

## 🚀 단계별 개발 로드맵 (Roadmap)

### 🔹 Phase 1: 싱글플레이어 프로토타입
- [ ] XR Interaction Toolkit 기반 VR 조작계 세팅
- [ ] 장검(Longsword) 기본 파지(한손/양손) 및 릴리즈 구현
- [ ] 트리거 입력 기반 `Normal` / `Combat` 모드 전환 및 조이스틱 이동 차단 로직 구현

### 🔹 Phase 2: 물리 연산 및 중량 시스템 고도화
- [ ] 프레임별 컨트롤러 가속도 측정 및 한손/양손 가중치 공식 적용
- [ ] 실제 컨트롤러 위치와 가상 무기 간의 `Configurable Joint` 기반 추적 딜레이(중량감) 구현
- [ ] 내려찍기 시 종단 가속도 오버라이드 시스템 구현

### 🔹 Phase 3: 1대1 스팀 네트워크 동기화
- [ ] Steamworks.NET 연동 및 1대1 매치메이킹 룸 생성 구현
- [ ] Photon Fusion을 활용한 검 충돌, 타격 판정 및 패링(Parry) 동기화
- [ ] 지연 시간(Lag) 최소화를 위한 클라이언트 사이드 예측(Prediction) 적용

### 🔹 Phase 4: 콘텐츠 확장 및 폴리싱
- [ ] 타격감 증대를 위한 컨트롤러 햅틱 피드백, 사운드, 스파크 이펙트 추가
- [ ] 무기 데이터를 스크립터블 오브젝트화하여 대검, 단검 등 신규 무기군 확장 테스트
